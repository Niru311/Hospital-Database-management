# Hospital-Database-management
Hospital database management using python and streamlit
A complete Hospital Management System built with Streamlit and MySQL to manage patients, billing, and appointments efficiently through an intuitive web interface.

🚀 Features
🔐 User Login Authentication

👨‍⚕️ Add & View Patients

💳 Add & View Bills

🔍 Search Patients & Bills

📅 Schedule & View Appointments

📊 Dashboard Overview with Metrics

✅ Uses Stored Procedure for billing (MySQL CALL AddBill(...))

🔒 Session-based authentication with Streamlit Session State

Tech	Description
